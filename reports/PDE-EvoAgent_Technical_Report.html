PDE-EvoAgent 技术报告

基于 LLM 多 Agent 协作的 PDE 神经算子自动演化系统

案例研究: 1D Diffusion-Sorption (diff_sorp) 方程  |  2026-08-04

系统概述
PDE-EvoAgent 通过四个专业化 LLM Agent（Proposal / Dev / Diagnosis / EvalReflection）在 Captain 调度器编排下， 自动完成「分析瓶颈 → 提出假说 → 修改代码 → 训练验证 → 评估判定」的完整科研闭环。 给定一个新 PDE 数据集，系统自动选择最优神经算子架构并通过迭代演化持续提升精度。

七、Agent 自主优化行为规律总结

7.1 Agent 决策模式分类

通过对两轮 Evolution 的完整追踪，我们归纳出 Agent 系统的三种核心行为模式:

模式触发条件Agent 行为结果出现频率
模式 A: 策略冲突型 Agent 提出的修改目标与现有系统功能重叠 Proposal 建议修改训练策略 → Dev 生成冲突代码 → 训练不稳定 → EvalReflection 判 DEGRADED → Captain 回退 退化，但被纠错机制捕获 R1 (50%)
模式 B: 架构增强型 Agent 选择纯粹的模型架构参数修改 Proposal 提出有物理依据的架构改进 → Dev 精确修改 → 训练稳定 → EvalReflection 判 IMPROVED → Captain 更新 baseline 成功改善 R2 (50%)
模式 C: 历史学习型 Agent 收到前一轮失败的历史信息 Proposal 避开已失败的方向，选择新的改进角度。Round 2 的 Proposal 在收到 Round 1 失败信息后，自觉避免修改训练策略 规避已知陷阱 R2 中体现

7.3 自我纠错机制的有效性

三层纠错体系
第 1 层 — 语法+实例化检查 (每次修改后): ast.parse + Python subprocess 验证。在所有实验中，Scout 和 Evolution 的每次修改都通过了此检查。

第 2 层 — EvalReflection 判定 (每次训练后): 分段指标 vs baseline 对比。Round 1 被正确判为 DEGRADED 并触发回退，保护了最优版本。

第 3 层 — Captain 回退机制 (DEGRADED 时): 自动恢复 model.py + checkpoint 到最优版本。Round 1 的回退是系统第一次激活此机制，执行正确，使 Round 2 从最优基线开始而非从退化版本开始。

7.4 关键行为规律

  1. 架构修改优于策略修改: Agent 在修改模型架构 (参数/层) 时成功率远高于修改训练策略。这是因为架构修改的影响范围更可控、更可预测。
  2. 历史记忆有效引导: Graph 记忆中的失败记录使 Proposal 能够避免重复踩坑。Round 2 的 Proposal 在收到 Round 1 失败信息后，自觉选择了完全不同的改进方向。
  3. 物理依据质量决定假说质量: Round 2 的假说之所以成功，关键是有清晰的数学解释 ("modes=12 仅捕获 9% 频率分量")，而非模糊的 "加大容量"。
  4. 信息不对称是主要风险: Round 1 失败的根源是 Proposal 不知道 Phase 2 rollout 已存在。在 Agent 系统中，"Agent 不知道系统已有功能" 是比 "Agent 能力不足" 更常见的失败模式。
  5. 回退 + 重试机制是安全网: 没有 Captain 的回退机制，Round 1 的退化修改会污染后续所有实验。回退保证了系统始终从最优版本出发。

八、"AI 自主科研"范式可行性评估与反思

8.1 本实验在自主科研光谱中的位置

我们将 AI 参与科学研究的程度分为五个等级:

等级人类角色AI 角色本实验达到?
L1: 工具辅助全部决策执行计算/画图-
L2: 建议辅助主要决策提供参考建议-
L3: 半自主实验设定目标、评估结果提出假说、执行实验、分析数据← 本实验
L4: 高度自主仅设定最终目标全部实验设计+执行+迭代-
L5: 完全自主无从问题发现到论文发表-

本实验处于 L3 级 (半自主实验)。人类设定了目标 (对 diff_sorp 数据集优化神经算子) 和评估标准 (比赛加权分)，AI 自主完成了实验设计、模型选择、假说生成、代码实现、训练执行和结果解读。

8.2 成功要素分析

使 AI 自主科研得以运转的关键设计
  1. 领域知识嵌入 Prompt: Proposal 的 System Prompt 包含 Burgers 方程专项知识 (激波特征、误差雪崩、守恒量)。diff_sorp 虽然不是 Burgers，但对 PDE 通用特性的理解 (频率截断、自回归误差) 仍然有效。
  2. 明确的状态空间: 模型选择限定为 4 个模板，修改限定为 model.py 内参数调整。这大大缩小了 Agent 的决策空间，避免了 "从零设计神经网络" 的无限可能。
  3. 可量化的反馈信号: seg1/seg2/seg3 分段 Rel-MSE 提供了精确的多维度反馈。Agent 不是在一维信号上盲目优化。
  4. 多层次安全机制: 语法检查 → 实例化检查 → 指标对比 → 回退保护，四层安全网确保系统不会因一次失败而崩溃。
  5. 共享记忆的可追溯性: Graph + Pool 使 Agent 能够 "记住" 历史，避免重复错误。这是纯 LLM 推理无法实现的能力。

8.3 局限性与风险

当前系统的主要局限
  1. 信息不对称: Agent 对系统现有功能 (如 train.py 的 Phase2 机制) 缺乏完整感知。Round 1 失败的核心原因。解决方案: 在 Proposal 的上下文中显式包含训练框架的功能清单。
  2. 探索空间狭窄: 4 个模板 + 参数调整的搜索空间远小于 "任意 PyTorch 代码"。系统无法发明全新的架构 (如 Transformer-based 算子)。
  3. 单轮成本高: 一次全量训练 80-100 分钟。在更大模型/数据集上，Agent 迭代速度将成为瓶颈。
  4. 没有实验设计优化: Agent 不质疑训练超参数 (学习率、batch size、epoch 数) 是否合理。这些是由人类预先设定的。
  5. 缺乏多轮统计分析: Agent 只做单次训练对比，没有重复实验或统计显著性检验。指标波动 (<5%) 被简单标记为 STAGNANT。

8.4 对 AI 自主科研范式的反思

核心命题: LLM Agent 能否产生真正的科学创新?

本实验中，Proposal 生成的假说均基于已知的物理原理 (傅里叶截断、自回归误差累积) 和已有的架构设计模式 (增加模态数、扩大通道)。这提出了一个深层问题:

假说的 "创新" 性质分析
假说是否已知?创新程度
"多步 rollout 损失训练"是 — 标准做法，且系统已实现无创新 (且冲突)
"扩大 Fourier modes + width"是 — FNO 论文的标准超参数建议低创新，但在该特定数据集上首次验证

我们的判断是: 在当前阶段，LLM Agent 的 "创新" 更准确地说是一种 "智能搜索"—— 在已知的物理原理和设计模式空间中，找到适合当前问题的组合。它不会提出 "用图神经网络替代傅里叶变换" 这样的范式级创新，但它可以在给定的范式内快速找到局部最优。

价值重估: AI 自主科研的真正价值在哪里?

重新审视 AI 自主科研的价值，不应以 "能否超越人类科学家" 为标准。它的真正价值在于:

  1. 超线性探索: 一个人类研究者可能需要数周来评估 4 个模型 + 2 轮优化。AI 在 4.5 小时内完成，且不疲劳、不遗忘、不偏见。
  2. 系统性的可复现: 每一个决策、每一行修改、每一个指标都被完整记录。这提供了人类科研中罕见的完全可追溯性。
  3. 互补而非替代: 人类擅长提出新范式 (如 FNO 的发明)，AI 擅长在给定范式内穷举优化。两者的结合——人类设定方向，AI 执行探索——可能是近期最有效的科研模式。

通向 L4/L5 的关键瓶颈

从 L3 (本实验) 迈向 L4 (高度自主) 需要突破以下瓶颈:

  1. 从参数调整到结构创新: Agent 需要能生成全新的 PyTorch 模块，而非仅修改已有模板的参数。这需要更强的代码生成能力 + 更强的自动化验证 (不仅仅是 shape check)。
  2. 从单次验证到统计推断: Agent 需要理解实验结果的统计不确定性，并能自主决定是否需要重复实验。
  3. 从固定评估到目标自适应: Agent 应能根据实验结果自主调整评估标准和搜索策略，而不是按固定的比赛公式优化。
  4. 从单任务到跨任务泛化: Agent 在 diff_sorp 上学到的经验 (如 "FNO 适合平滑解") 应能迁移到下一个 PDE 任务，而不是每次从零开始。

8.5 实验结论

PDE-EvoAgent 在 diff_sorp 数据集上成功演示了 L3 级 AI 自主科研的可行性。系统在 4.5 小时内自主完成了从数据探测到模型优化的完整闭环，最终产出了一个经过验证的改进模型 (FNO+ 比原始 FNO 的 seg1 改善 11%，seg2 改善 12%)。

这次实验也清晰展示了当前 AI 自主科研的边界: Agent 本质上是 "已知知识的智能搜索器" 而非 "新知识的创造者"。它的价值在于速度和完备性，而非范式创新。然而，对于大量 "给定框架、寻找最优配置" 的科研日常工作，这种能力已经具有实质性的生产力价值。

核心结论
  1. FNO 是光滑扩散型 PDE 的最优架构。傅里叶截断 = 天然谱正则化，23K 参数即达 4e-06 精度。
  2. Scout 以 1/20 成本正确预测排名。17 min vs ~6h，小样本快速筛选在 PDE 算子选型中高度有效。
  3. Round 1 失败为 Prompt 设计提供关键反馈。Proposal 不应修改训练策略 (train.py 已有 Phase2)，应聚焦架构创新。
  4. Round 2 用简洁且有物理依据的改进成功。扩大 modes+width，seg1/seg2 各改善 11-12%，全部自主决策。
  5. 全程零人工干预，4.5 小时完成。数据探测 → Scout → 2 Baseline → 2 Evolution → 终模。证明了 LLM-driven PDE 算子自动演化的可行性。
