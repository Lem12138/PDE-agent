本轮在 **FNO1d** 的每个 Fourier block 里并联一条 `kernel_size=3` 的局部分支（离散差分算子），用 `gamma`（初值 0）做残差缩放，使该分支**初始化时为 no-op**，从而保护已饱和的 seg2/seg3，只在高频残差方向生长。

**改哪、为什么：**
- `__init__`：在 `w0..w3` 之后新增 `local_conv0..3`（`Conv1d(width, width, k=3, pad=1)`，小尺度初始化）+ `gamma0..3`（`zeros(1)`，可学习标量）。卷积 `kernel=3, padding=1` **保持 N 不变**，`gamma=0` 保证初始 no-op。
- `forward`：把每个 block 的 `x = x1 + x2` 改为 `x = x1 + x2 + self.gammaK * self.local_convK(x)`。谱分支管全局低频（保 seg2/seg3），局部分支补被 modes 截断的陡峭锋面高频（攻 seg1）。

**I/O 与 shape 检查**：`local_conv(Conv1d, k=3, pad=1)` 输入输出长度不变；`gamma` 为标量逐元素广播；全程在 `(B, width, Nx)` 上相加，`forward` 输入 `(B,N,T_in)`→输出 `(B,N,1)` 不变。

**唯一性说明**：FNO2d/FNO3d 的 `forward` 里 conv block 文本与 FNO1d 完全一致，故不能用单个 conv block 做 SEARCH；我用 `x = x.permute(0, 2, 1)` + `# pad the domain` 作为锚点，仅 FNO1d 具备该组合（2D 是 `permute(0,3,1,2)`，3D 是 `permute(0,4,1,2,3)`），保证 SEARCH 唯一。

改动后：
- `local_convK` 为 `Conv1d(k=3, pad=1)`，空间长度 N 不变，`gamma=0` 时输出与原来完全一致（no-op），checkpoint 中旧权重可平滑复用（新增参数量极小，若框架 `strict=False` 加载不会报错）。
- 训练开始后 `gamma` 从 0 逐步生长，局部分支仅在被高频残差推动的方向（sorption 锋面）起作用，避免扰动已≈0 的 seg3。
- 验证重点看 seg1 是否下降 10–30%；若 seg2/seg3 抬头 >10%，说明注入高频过量，可把 `gamma` 初值进一步压小或对 `local_conv` 加 weight decay（回退路径）。
