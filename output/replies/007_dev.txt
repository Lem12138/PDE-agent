**Shape 校验（心智检查）**：输入 `(B, N, 10)` → fc0 → `(B, N, width)` → permute → `(B, width, N)` → pad(2) → `(B, width, N+2)`。`conv_i`(SpectralConv) 输出长度 N+2；`w_i`(1x1) 长度 N+2；`local_conv_i`(k=5,p=2) 长度 N+2，三者可相加。最后截断 `[..., :-2]` 回到 N → permute → fc1/fc2 → `(B, N, 1)` ✅。

**注意**：新增 4 个 `local_conv` 参数，会改变工程 checkpoint 的 key 集合。若 train.py 用 `strict=True` 从旧的 `best_phase2.pt` 热启动，需改 `strict=False`；若从头训练则无影响。
