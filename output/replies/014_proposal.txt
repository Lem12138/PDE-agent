## 诊断

从当前最优指标看，短板不在长时：seg1=5.70e-06 明显高于 seg2=3.78e-06（seg3 的 baseline 为 0，无法判定），说明误差主要来自**早期时段**。这正是 diffusion-sorption 类方程的典型特性：t≈0 附近吸附动力学（快时间尺度）与扩散（慢时间尺度）差了好几个量级，早期解在边界处存在极薄的陡峭过渡层，时间采样上表现为"前几步剧烈变化"。FNO 的谱卷积对空间做 **模态截断**（只保留前 modes 个波数），而边界层的特征尺度只有几个网格点，能量集中在高波数——截断后过渡层被"磨平"，误差在 seg1 里最突出。也就是说，瓶颈是**低通算子丢掉了边界层的高波数结构**，不是容量不足，也不是 rollout 策略问题。

## 本轮做什么

只做一个改动：在 FNO 的每个傅里叶层里，并联一条**深度可分离局部卷积的残差旁路**（高频补偿支路），并用一个零初始化的可学习门控叠加。这样做的效果是：模型初始状态与当前最优 checkpoint 的行为**完全一致**（门控 = 0），训练只在确实需要高频细节时才打开这条支路，因此不存在"改坏 seg2"的风险，也不改变模型规模数量级。这跟 R2/R3 那种改模态数、改宽度、改层数的超参调整不是一回事——那两个轮次改变的是同一个低通算子的带宽，而这里补的是**算子族本身缺失的局部（高波数）成分**。

## 改哪里

文件：`model.py`，仅此一个文件。

- 类：`model.py` 中 FNO 的频谱块（即包含 `SpectralConv1d` / `self.spectral` 的那个 `FNOBlock` / `FourierLayer` 类）。
- `__init__` 新增两个成员（width 用该块现有的通道数变量，不要写死）：
  - `self.local = nn.Conv1d(width, width, kernel_size=3, padding=1, groups=width, bias=False)`（depthwise，参数量 = 3×width，可忽略）
  - `self.hf_gate = nn.Parameter(torch.zeros(1))`（**零初始化**，关键）
- `forward(self, x)` 中，把原来的
  `x = self.spectral(x) + self.w(x)`（或 `x = self.conv(x) + self.spectral(x)`，以现有代码为准）
  改为：
  ```python
  x = self.spectral(x) + self.w(x) + self.hf_gate * self.local(x)
  ```
  激活函数位置、残差、输出层、`forward` 的输入输出签名一律不动，I/O shape 完全不变。

不改 `train.py`、不改损失、不改 rollout、不改 modes / width / n_layers。

## 为什么

FNO 的单层算子可写成 `W·x + F⁻¹(K̂ ⊙ F(x))`，其中 `K̂` 在 |k| > modes 处被强制置零，等价于一个**固定的理想低通滤波器**。对 diffusion-sorption 的早期解，边界层厚度 δ ~ O(√(D·t))，t 最小时 δ 仅为几个网格步长，其傅里叶谱的高波数分量能量占比不可忽略；截断会引入 Gibbs 型振荡/钝化，误差直接计入 seg1。`kernel_size=3` 的 depthwise 卷积的频响近似 `1 + 2cos(kΔx)/3`，在 Nyquist 附近不衰减，恰好补上被置零的那一段高频；而 `hf_gate` 零初始化保证初始时刻该支路贡献为 0，优化器只在"高频误差确实能降低总损失"时才把它推离 0，因此这是一个**单调安全**的容量注入，不会像 R3 那样牺牲 seg1 去换 seg2。

## 怎么验证

- 主指标：`seg1`。预期从 5.70e-06 下降 ≥10%（到 5.1e-06 以下），`seg2` 变化在 ±5% 以内，`overall` 同向下降。
- 反向判据：若 `seg1` 持平而 `seg2` 变差，或 `overall` 上升超过噪声阈值，直接回退（把 `hf_gate` 那条加法删掉即可）。
- 诊断副产物：训练后打印各层 `hf_gate` 的绝对值。若全部趋近 0，说明高频误差不是本数据 seg1 的主因（那下一步应转向时间维的 stiff 处理，而不是空间谱）；若深层 gate 明显大于浅层，说明误差确实在后段被逐层低通放大，可据此决定是否只保留深层支路。
