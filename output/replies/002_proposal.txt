## 方案：为 FNO 的傅里叶层并联"局部差分卷积"分支，专治 seg1 的陡峭 sorption 锋面

**诊断**：三个段里 **seg1 是短板**（6.56e-6，RMSE≈2.6e-3，相对误差≈1%，比 seg2 高约 40%）；seg3=0 说明长时段已被完全解析。这不是自回归误差雪崩型瓶颈——恰恰相反，因为 1D diffusion-sorption 是**耗散型抛物方程**，长时间解会弛豫成光滑的低阶剖面，被 FNO 的低频 modes 完美捕获（故 seg3→0）；真正难的是**瞬态初期 sorption 锋面附近那段最陡的空间梯度**，它的高频能量被 FNO 的 modes 截断直接抹平，残差就集中落在 seg1。根因是**谱截断对陡峭局部锋面欠分辨**，而非容量或 rollout 问题。

**本轮做什么（P0）**：在 FNO 的每个傅里叶层里，并联一条**局部差分卷积（local stencil）分支**，与现有谱卷积输出相加。谱分支负责全局低频光滑结构（保住已饱和的 seg2/seg3），局部卷积分支补上被截断的高频/陡峭梯度（专攻 seg1）。只改 `model.py`，不动 train.py、不动 I/O、不改 rollout。

**改哪里**：
- 文件：`model.py`
- 类：FNO 的 **FourierLayer / SpectralConv 所在层**（每个 Fourier block）
- 改动：
  1. `__init__` 里新增 `self.local_conv = nn.Conv1d(width, width, kernel_size=3, padding=1, groups=1)`，并对该层做**小尺度初始化**（如 `nn.init.normal_(weight, std=0.01)`，bias=0），或加一个可学习标量 `self.gamma = nn.Parameter(torch.zeros(1))` 作残差缩放。
  2. `forward` 里把
     `x = self.act(self.spectral_conv(x) + self.w)`
     改为
     `x = self.act(self.spectral_conv(x) + self.w + self.gamma * self.local_conv(x))`
- 不碰 `forward` 的输入/输出 shape（仍在 `(B, width, Nx)` 上逐元素相加）。

**为什么**：FNO 的算子核本质是**全局低秩谱乘子**，对低频长程结构最优，但对空间上局部、陡峭的梯度（sorption 锋面）等效于一个被截断的高频滤波器，会系统性地钝化锋面。一个 `kernel_size=3` 的 `Conv1d` 正是**局部有限差分算子**（一阶/二阶导的离散近似），它提供的是谱卷积缺失的**局部、高频、非低秩**成分；两者相加 = "全局谱算子 ⊕ 局部差分算子"的分解，直接针对陡峭锋面的欠分辨问题。`gamma` 从 0 开始意味着该分支**初始为 no-op**，训练时只在高频有残差的方向生长，从而**保护已达 ~0 的 seg2/seg3 不被扰动**——这比单纯加大 modes 更安全（加大 modes 会把高频噪声也引入，可能反噬已经很干净的长时段）。

**怎么验证**：
- 主看 **seg1**：预期下降 10–30%（RMSE 2.6e-3 → ~2e-3），overall 随之微降。
- **回归护栏**：seg2、seg3 应基本持平（seg3 仍≈0）。若 seg2/seg3 抬头 >10%，说明局部分支注入了不该有的高频 → 把 `gamma` 初值压更小、或 kernel 降回 3/加 weight decay，即回退。
- 若 seg1 也没动，说明瓶颈不在此锋面高频（可能是时间积分误差），Captain 可基于新状态再问，届时转 P1 方向（例如在 FNO 前加一层固定二阶导的残差预处理）。
