## 诊断

先看指标结构：seg3=0.0 属于不可判定段（baseline 为 0/缺失），不参与优化；真正可比的是 **seg1=5.70e-6 与 seg2=3.78e-6**。seg1（短时）误差比 seg2 高约 50%，且 overall 几乎由 seg1 主导——**seg1 是当前唯一的短板**，seg2 反而更好。

这与物理机制吻合：本数据是 1D diffusion-sorption（`1D_diff-sorp`，场值 ∈[0,1]，含非线性吸附/阻滞效应），早时段的解由**注入边界（x=0 附近）的边界层 + 一个较陡的吸附/输运前缘**主导。FNO 的谱卷积完全建立在 FFT 上，天然隐含**周期性假设 + 低频谱偏置**：在非周期边界处引入 Gibbs 振铃、在前缘处把陡梯度抹平。这部分误差在短时段最集中，正好对应 seg1 偏高。所以短时误差的根因不是容量不够，而是**纯谱算子对局部陡前沿与非周期边界缺乏表达能力**。

## 本轮做什么（只做这一个）

在每个 Fourier 层里，给谱卷积分支旁**并联一条物理空间的小核卷积分支**（local operator），与谱输出相加后再激活。谱算子负责平滑的全局输运，小核卷积负责陡前缘/边界层的局部高频，两者互补，直接压制 seg1 的来源误差。

## 改哪里

只改 `model.py` 的 FNO 及其层封装，不动 `forward` 的 I/O shape。

1. **在 FNO 的 `__init__` 中新增一个 ModuleList**（与现有 `w_layers` 同一层级）：
   ```python
   # 新增
   self.loc_layers = nn.ModuleList([
       nn.Conv1d(width, width, kernel_size=3, padding=1, padding_mode='reflect')
       for _ in range(n_layers)
   ])
   ```
   - `kernel_size=3, padding=1`（保持长度 1024 不变）
   - `padding_mode='reflect'`：对应无流/Neumann 边界，避免 FFT 的周期性假设污染边界
   - 若确认 x 方向是周期域，则改为 `padding_mode='circular'`

2. **在 FNO 的 `forward` 层循环里**，把每层更新
   ```
   x = F.gelu(spectral_layer(x) + w_layer(x))
   ```
   改成
   ```
   x = F.gelu(spectral_layer(x) + w_layer(x) + self.loc_layers[i](x))
   ```
   （若现有实现是把 `w` 作为残差直连 `x + spectral`，则把 `loc` 同样加到该残差上，位置在激活之前。）

参数量增量：每层 `3×width×width`，对 width~几十而言可忽略；1D、kernel=3 的卷积计算量极小，**不影响 <2min 推理约束**。

## 为什么（数学/物理依据）

- **FNO 的谱偏置**：截断 modes 的谱卷积本质是低通算子，对高频局部结构（陡前缘）系统性抹平——这是 FNO 处理 sharp/local feature 的已知缺陷，也是 U-FNO/TFNO 引入局部核的共同动机。
- **FFT 的周期性假设**：本问题边界非周期（注入边界 + 无流边界），纯 FFT 在边界产生 Gibbs 伪振荡，误差在早时段边界层处最大 → 正好落在 seg1。
- 小核卷积在物理空间、局部感受野、不依赖 FFT，既补上高频前沿，又绕开边界周期性假设，是“低频全局(谱) + 高频局部(卷积)”的正交分解，理论上与现有谱分支互补而非重复。

## 怎么验证

主看 **seg1**：预期下降 ≥10%（overall 随之下降）。**seg2** 预期持平或小幅改善；若 seg2 相对当前 3.78e-6 恶化超过 10%，说明局部分支抢占了谱分支的平滑输运、rollout 更不稳，需回退（例如把 `loc` 换成 kernel=1 的纯逐点）。同时确认无 NaN、训练步时间增幅在可接受范围。
