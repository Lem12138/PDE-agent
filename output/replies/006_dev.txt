## 本轮修改说明

**改什么**：只在 `SpectralConv1d` 内部做两处改动——
1. `__init__` 新增 `self.pad_ratio = 0.5`（纯超参，无参数、无 checkpoint 影响，因为它不是 `nn.Parameter`/buffer，state_dict 不会被污染，旧的 ckpt 仍能 load）。
2. `forward` 里在 `rfft` 之前把最后一维右侧补零扩到约 1.5×，`irfft` 之后再裁回原长。

**为什么**：diffusion‑sorption 的浓度锋面在入口附近有强梯度，域两端不满足周期性；`rfft` 隐含"场是周期的"，于是边界阶跃在频谱里形成 Gibbs 振铃，能量漏到高频后被 `modes1` 截断丢掉，误差就集中在最陡的早期段（seg1）。右侧补零让真实场与零背景平滑衔接，把边界不连续推离信号支撑区，降低混叠与截断误差（FNO 原论文的标准 padding trick）。它只作用在谱计算内部，不新增可训练参数、不改拓扑，对已光滑的 seg2 应基本中性。

**I/O shape 检查**：补零与裁剪都在 `SpectralConv1d.forward` 内部成对完成，`out` 最后一定是 `(B, out_channels, N)`，`N` 与进入该层时**完全一致**；`w0..w3` 的 1×1 旁路和 `local_conv*`（padding=1）路径的 N 都不受影响；`FNO1d.forward` 末尾的 `x[..., :-self.padding]` 与输出 `(B,N,1)` 完全不动。所以 `torch.randn(2,256,10) → model(x, grid)` 仍是 `(2,256,1)`。

**顺带做的稳健化**：模态切片用 `m = min(self.modes1, x_ft.shape[-1])` 双向夹紧，即使以后 `pad_ratio` 调大或 `modes` 调大也不会越界。

    def forward(self, x):
        batchsize = x.shape[0]
        N = x.shape[-1]

        # --- domain padding (before FFT) -------------------------------------
        # Zero-pad the spatial axis on the right so that the (non-periodic)
        # boundary is separated from the signal support in the periodic
        # extension used by rfft. Reduces Gibbs / aliasing at sharp fronts.
        if self.pad_ratio > 0:
            pad = int(self.pad_ratio * N)
            if pad > 0:
                x = F.pad(x, (0, pad))
        Np = x.shape[-1]

        # Compute Fourier coefficients up to factor of e^(- something constant)
        x_ft = torch.fft.rfft(x)

        # Multiply relevant Fourier modes
        out_ft = torch.zeros(
            batchsize,
            self.out_channels,
            Np // 2 + 1,
            device=x.device,
            dtype=torch.cfloat,
        )
        m = min(self.modes1, x_ft.shape[-1])
        out_ft[:, :, :m] = self.compl_mul1d(x_ft[:, :, :m], self.weights1[:, :, :m])

        # Return to physical space (padded length)
        out = torch.fft.irfft(out_ft, n=Np)

        # --- crop back to the original spatial length -------------------------
        if Np != N:
            out = out[..., :N]
        return out
